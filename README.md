# Exercise SD-XL

Proyecto en Python que utiliza el modelo **Stable Diffusion XL Base 1.0** de Hugging Face para generar imágenes mediante Inteligencia Artificial Generativa.

## Tecnologías
- Python
- Hugging Face
- Stable Diffusion XL
- uv

## Resultado
Genera imágenes a partir de descripciones de texto (*prompts*).
